## 📖 What is this project?

A fully automated SIP (Session Initiation Protocol) server setup tool. With just one command, you can deploy a complete SIP server on your VPS along with a ready-to-use SIP account. Perfect for VoIP calling and internet telephony services!

## ⚡ One Command Install (SIP Server + SIP Account)

Copy and paste this command into your VPS terminal:

```bash
git clone https://github.com/shadinislam01/sip-trunk-vps.git && cd sip-trunk-vps && sudo bash install.sh

```

🗑️ One Command Uninstall (Complete Removal)

If you want to completely remove the SIP server, run this command:

```bash

cd sip-trunk-vps && sudo bash uninstall.sh
